PC の Wi-Fi の一覧netsh の例
SSID 1 : <ネットワーク名>
    BSSID 1   : 00:00:5e:00:53:01
         シグナル : 96%
    BSSID 2   : 00:00:5e:00:53:02
         シグナル : 66%
スクリプトが行うこと
  • 1BSSID とシグナルを取り出す
  • 2シグナルを受信信号強度に換算する
2 の換算は近似
Windows の netsh のシグナル
dBm ≒ シグナル ÷ 2 − 100
Linux の nmcli の SIGNAL
dBm ≒ SIGNAL × 0.6 − 100
Linux の iw
dBm を直接表示する
  • 3ローカル管理アドレスを除く
  • 4強い順に最大 10 台を残す
  • 5SSID は書き出さない
  • 6MAC アドレスを
    大文字・コロン区切りにそろえる
